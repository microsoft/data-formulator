**Example**

Region `us-east-1`, bucket `my-data-bucket`

**Credentials**

In AWS Console, open **IAM → Users → Security credentials → Create access key**. Enter the access key ID and secret access key. Temporary credentials also require the session token.

**Access**

The IAM identity needs `s3:ListBucket` on the bucket and `s3:GetObject` on the files you want to load.

**Files**

Supported formats: CSV, Parquet, JSON, and JSONL.
