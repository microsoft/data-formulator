**Example**

host: `localhost` · port: `8123` · username: `default`

**Connection**

ClickHouse Cloud uses port `8443` with `secure` turned on. Self-hosted servers usually use HTTP port `8123`.

**Credentials**

Use an account that can read the databases you need. On a local install, `default` often has no password.

**Scope**

Leave `database` empty to browse every database, or enter one to open its tables directly.
