**Example**

url: `https://bi.company.com`

**Credentials**

Use an account with at least the **Gamma** role and read access to the datasets you need. If your Superset uses SSO, sign in with SSO instead; it's shown when the server sets `PLG_SUPERSET_SSO_LOGIN_URL`.

**Check**

Use the base URL, not a link to a dashboard or chart.
