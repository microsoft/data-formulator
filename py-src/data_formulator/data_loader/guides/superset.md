**Example**

Superset URL `https://bi.company.com`

**Credentials**

Enter a Superset username and password. The account should have at least the **Gamma** role and permission to read the required datasets.

If the deployment uses SSO, use the configured SSO sign-in flow instead of entering a password. The server operator must configure `PLG_SUPERSET_SSO_LOGIN_URL` for that option to appear.

**Check**

Use the base Superset URL, without a dashboard or chart path.
